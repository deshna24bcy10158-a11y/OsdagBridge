
## Software Testing & Issue Reporting

Testing was performed on OsdagBridge as part of an internship assignment.

### Testing Completed
- Three consecutive design runs with spans of 30 m, 31 m, and 32 m.
- Custom material selection testing.
- Concrete deck thickness persistence testing (250 mm to 260 mm).
- 3D CAD model and structural plot verification.
- Design summary and report generation.
- Source-code inspection of input and output dictionary handling.

### Results
All three main design runs completed successfully and displayed PASS in the design summary.

No confirmed software defect was identified during the completed tests.
